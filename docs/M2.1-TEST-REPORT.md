## Limits and residual gates

Static secret scans are heuristic; they cannot prove every possible credential/personal fact is absent. No browser profiles, user credentials, `.env`, caches, node_modules or Git history are included in source archives. Only intentional synthetic test credentials occur in tests. The built extension contains no fixture provider responses/test bundles. API CORS, provider availability/limits, native permissions and worker lifecycle still need authorized real-Chrome/account acceptance. Passing mocked adapters does not certify every model/provider account.
